Сначала активируй игровое окно правой кнопкой. Только потом кликай левой.

ПКМ в макрос не попадает
!

Перед каждым ЛКМ — ПКМ по окну игры. Запись левого клика срабатывает только тогда, когда игровое окно активно. Клик по самому HemP игнорируется. Вернулся в программу за кнопкой — снова активируй игру правой кнопкой, иначе следующий ЛКМ пропадёт.

Базовый макрос

01 / ЗАПИСЬ
  1. Выбери окно игры.

    Запись привязывается к выбранному окну. Если открыто несколько клиентов — сначала выбери нужный в HemP. Окно игры должно быть видно, не свёрнуто.

  2. Нажми «⏺️ Начать запись» или Ctrl+1

    Переключись в игру. Статус в HemP должен показывать, что запись идёт.

  3. Расставь контрольные точки.

    «Точка: добежать», «Точка: убить» с количеством мобов, «Точка: босс». Бег не пишется — маршрут задают точки.

    Для точек убийства можно указать скилл X,Y и включить автоповтор.
  4. Нужен клик — активируй окно правой кнопкой.

    ПКМ по игровому окну → ЛКМ по цели. Правая кнопка не записывается, она только возвращает фокус.

  5. Останови и сохрани.

    Ctrl+2 или «⏹️ Завершить запись» → введи имя. Макрос появится в списке.

NPC и диалог

02 / NPC

Порядок важен: задержка → двойной клик по NPC → проверка диалога → клики по строкам.

01

Добавь задержку перед каждым NPC

Кнопка «Задержка», поле «мс» — 2000 по умолчанию. Если NPC далеко или долго подходит, поставь 2500–3000. Задержка добавляется в конец макроса — сделай это до клика по NPC.

02

Активируй окно игры

ПКМ по игровому окну. Не пропускай этот шаг: без фокуса двойной клик не запишется.

03

Дважды кликни по NPC

Два быстрых ЛКМ по одной точке. В списке появится «Двойной клик [x,y]».

04

Поставь «Проверку диалога»

Вернись в HemP и нажми «Проверка диалога» сразу после клика по NPC. Кнопка работает только во время записи.

05

Запиши первую строку

ПКМ по окну игры → ЛКМ по тексту первой строки. HemP сам сохранит её как «Диалог: '…'».

06

Повтори для следующих строк

Для каждой следующей строки: ПКМ по окну → ЛКМ по строке. Новую проверку диалога не добавляй.

Зачем проверка после клика. На воспроизведении HemP ждёт открытия диалога. Если он закрыт, программа один раз повторит последний клик по NPC и подождёт 2 секунды. Если диалог так и не открылся — вернётся к предыдущей контрольной точке.

Кнопки записи

03 / ПАНЕЛЬ

Всё, что есть в карточке «Запись макроса». Кнопки шагов работают только при идущей записи.

⏺️ Начать записьCtrl+1

Включает захват и привязывает макрос к выбранному окну. Если в этот момент играл другой макрос — сначала остановит его. Бег, ПКМ и клавиши не пишутся.

⏹️ Завершить записьCtrl+2

Останавливает захват и просит имя макроса. Запись без шагов не сохраняется. Готовый макрос сразу появляется в списке ниже.

Точка: добежатьчекпоинт

Запоминает текущую позицию и камеру. На воспроизведении персонаж бежит сюда и выполняет клики до следующей точки. Это основной способ задать маршрут.

Точка: убить+ мобов: N

Зачистка у точки: убить N мобов. Если заполнены «скилл x,y», бьёт скиллом по цели; мобы с HP выше 1,5 млн пропускаются, чтобы не влезть в босса.

Точка: боссчекпоинт

Ищет босса в 40 м. Если ты не в 1–4 м от него, сначала подбегает на 2,5 м и только потом ставит точку. На воспроизведении: подход, дебафф, бой до 10 минут, затем лут и бафф по настройкам.

Вывод босса+ вывод x,y

Точка вывода. На воспроизведении ищет босса в 20 м, до 20 секунд добирает цель через Tab и один раз бьёт скиллом по указанным координатам. Ставь перед точкой убийства босса.

Проверка диалогашаг

Проверяет, что диалог открыт после клика по NPC. Если закрыт — один раз повторяет клик и ждёт 2 секунды. Если не открылся, возвращает макрос к предыдущей точке.

Задержка+ мс: 2000

Вставляет паузу. По умолчанию 2000 мс. Нужна перед каждым NPC и везде, где игра должна успеть доехать, открыть окно или проиграть анимацию.

Найти моба+ радиус м: 25

Ищет ближайшего моба в радиусе и берёт его в таргет. Не убивает — только выбирает цель для следующих шагов. Если моб не найден, макрос идёт дальше.

Набив Чишаг

Два клика по точке Чи из настроек с паузой между ними (по умолчанию 5 секунд). Если координаты Чи не заданы, шаг пропускается.

Координаты в полях X,Y: кликни поле в HemP, наведи курсор на нужное место в игре и нажми Ctrl+A. Рядом с точками убийства есть скилл x,y и автоповтор: без повтора скилл жмётся один раз на цель, с повтором — каждые 1,5 секунды, пока цель жива.

Шаги проверяются и правятся в «Редакторе шагов»; там же добавляются «Подбор лута» и «Бой по списку».

«Проверка диалога» не добавилась Кнопка нажата вне записи Кнопки точек, задержки и проверки активны только при идущей записи.
