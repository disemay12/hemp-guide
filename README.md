# HemP — руководство по модулям

Статический сайт-руководство по HemP/Perfect World. Четыре вкладки: **Бот**, **Пилот**, **Мульти**, **Комка**. Для каждого модуля — быстрый старт, разбор интерфейса, настройки и таблица частых проблем.

## Просмотр

https://disemay12.github.io/hemp-guide/

## Что внутри

- **Бот** — запись макросов, точки, NPC и диалоги, редактор шагов, список макросов, мультиокна, запуск по Bat, авто-пот и авто-хирка.
- **Пилот** — текстовые и Lua-сценарии, привязка окон, редактор, команды, запись, HUD и общий хоткей.
- **Мульти** — поиск окон по заголовку, Follow, Assist, Chat, MultiClick, хоткеи, пиксельный бот и воскрешение.
- **Комка** — координаты комиссионки, скан лавок, отчёт, бюджет, приоритет и Telegram-команды.

## Технически

`index.html` — один самодостаточный файл: инлайн CSS и JavaScript, без внешних зависимостей, шрифтов и картинок. Все схемы нарисованы на HTML/CSS/SVG специально для этого руководства; скриншотов программы нет. Страница открывается напрямую с диска и работает на GitHub Pages.

## Локальный запуск

Откройте `index.html` в браузере. Для проверки вкладок можно открыть файл с хэшем:

```
index.html#bot
index.html#pilot
index.html#multi
index.html#komka
```

Глубокие ссылки на разделы: `#bot-record`, `#pilot-editor`, `#multi-follow`, `#komka-coords`.
